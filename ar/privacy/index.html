المعلومات التي نستلمها

لا يخزن هذا الموقع التجريبي بيانات طلبات التواصل. إذا تواصلت مع KPG عبر الهاتف أو واتساب أو إنستغرام أو البريد الإلكتروني، فتعالج تلك الخدمات المعلومات التي تقدمها وفقا لشروطها.

كيفية استخدام المعلومات

عند ربط خدمة طلبات مباشرة، ستستخدم KPG المعلومات المقدمة للرد على الاستفسارات وإعداد العروض المطلوبة وتنسيق المشاريع والوفاء بالالتزامات القانونية المعمول بها.

المشاركة والاحتفاظ

لن تتم مشاركة المعلومات إلا مع مزودي الخدمة أو أطراف المشروع عند الحاجة للخدمة المطلوبة أو إذا تطلب القانون ذلك، وسيتم الاحتفاظ بالسجلات للمدة الضرورية فقط.

خياراتك
